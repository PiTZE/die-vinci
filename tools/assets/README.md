# mona-lisa.svg

Source for the app icons. Not shipped: it is 449KB, and 199KB even gzipped,
which is more than nine times the entire game bundle. `npm run icons`
rasterises it to the PNGs in `public/` and only those are deployed.

- File: [Mona Lisa vectorized.svg](https://commons.wikimedia.org/wiki/File:Mona_Lisa_vectorized.svg)
- Author: Sebastian Wallroth, from Leonardo da Vinci's painting
- Licence: CC0, public domain dedication. No attribution required, though it is
  given here anyway.

Chosen over the other Mona Lisa SVGs on Commons because it is the only one that
is both genuinely monochrome and free of attribution terms. `Monalisa.svg` and
`Face-ism Mona Lisa.svg` are diagrams that happen to contain the painting, and
`Stylized Mona Lisa.svg` is a colour cartoon under CC BY-SA 3.0.
